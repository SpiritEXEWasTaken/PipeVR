# PipeVR extractor

The site extractors PipeVR uses (YouTube, Twitch, Kick, Patreon, Floatplane, Rumble, Odysee, Dailymotion, Vimeo, Nebula and the others). They're a fork of [PipePipeExtractor](https://github.com/InfinityLoop1308/PipePipeExtractor), which is based on [NewPipeExtractor](https://github.com/TeamNewPipe/NewPipeExtractor) and licensed under the GPLv3.

You don't build this folder on its own: the app's build in the repository root includes it.
